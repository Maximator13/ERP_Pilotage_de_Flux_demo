# EOLIA ERP – démonstrateur

Démonstrateur d'ERP industriel pour EOLIA, entreprise fictive de tôlerie, assemblage et mécanique, réalisé dans le cadre du cours « Pilotage » (remplacement de Manufacturing PMI).

**Voir la démo :** https://maximator13.github.io/ERP_Pilotage_de_Flux_demo/

Flux couvert : devis → commande (réf. client → réf. interne unique) → nomenclature par client → besoins nets et allocations → achats et réception (PMAP) → OF, pointage atelier, non-conformités → préparation, BL partiels → facturation et export comptable.

Priorisation 80/20 : les 7 actions critiques du plan d'amélioration sont démontrées chacune dans une page.

- `index.html` : application autonome (aucune dépendance externe, aucun cookie, calculs dans le navigateur).
- `EOLIA-acronymes.pdf` : glossaire des sigles utilisés.

Toutes les données sont fictives.
